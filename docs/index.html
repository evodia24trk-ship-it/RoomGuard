Model & Dataset

Model: Decision Tree (gini, max_depth 7, min_samples_leaf 10, class_weight balanced). Dataset: 2,000 rows — 1,500 public (stratified sample of UCI 864, 10,129 rows) + 500 private (phyphox, 30-second interval). Features: Light_Lux = mean of S1–S4 Light; Sound_dB converted from UCI Volts with 20·log10(V/0.05)+35. Labels follow a fixed standard: occupied if at least one person is physically in the room for the whole 30-second interval, headcount written in the attendance log before sensor values are read; transition intervals are discarded; two observers must agree.

Note: the 500 private rows currently in the repo are calibrated simulated data following the phyphox protocol — not real recordings yet. They must be replaced with real phyphox recordings and the model retrained before the presentation (see README).
